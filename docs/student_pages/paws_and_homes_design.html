How the screens behave

Login

  • Use a Form with GlobalKey<FormState>. Email must be a valid format. Password must be at least 8 characters.
  • The eye icon shows and hides the password with obscureText and setState.
  • When both fields are valid, show the loading spinner for 1.5 seconds, then open Home with Navigator.pushReplacementNamed(context, AppRoutes.home). pushReplacementNamed removes the login screen, so the back button doesn't return to it.
  • “Forgot password?” and “Create an account” can show a SnackBar saying “Coming soon” for now.
  • There's no real account check yet. Real sign-in with Firebase comes in Session 8, and this same screen will be reused.

Home

  • The greeting shows the part of the email before @, with a capital first letter. Send it to Home as the route's arguments, or keep it in a Riverpod provider if you've done Session 5.
  • Category chips filter the grid. The heart toggles a favourite. Keep both in Riverpod providers if you've done Session 5.
  • Tapping a pet card opens the Pet detail screen from the Paws & Homes brief.
  • Wrap the body in SafeArea and make it scrollable, so nothing overflows on a small phone or with large text.

Theme starter

Put this in lib/theme.dart. Every color and font on the screens should come from here, never from Colors.xxx in a widget.

import 'package:flutter/material.dart';

const _primary = Color(0xFF2F5D50);
const _ink = Color(0xFF1E2A26);
const _line = Color(0xFFDCE1DD);

ThemeData buildPawsTheme() {
  final colors = ColorScheme.fromSeed(seedColor: _primary).copyWith(
    primary: _primary,
    onPrimary: Colors.white,
    primaryContainer: const Color(0xFFE3EEE9),
    secondary: const Color(0xFFF2A65A),   // accent
    onSecondary: _ink,
    surface: Colors.white,
    onSurface: _ink,
    onSurfaceVariant: const Color(0xFF5F6B66), // muted text
    outlineVariant: _line,
    error: const Color(0xFFB3261E),
  );

  OutlineInputBorder border(Color c, double w) => OutlineInputBorder(
        borderRadius: BorderRadius.circular(12),
        borderSide: BorderSide(color: c, width: w),
      );

  return ThemeData(
    colorScheme: colors,
    scaffoldBackgroundColor: const Color(0xFFF5F6F1),
    fontFamily: 'NunitoSans',
    textTheme: const TextTheme(
      headlineMedium: TextStyle(fontFamily: 'Fredoka', fontSize: 30, fontWeight: FontWeight.w600),
      titleLarge: TextStyle(fontFamily: 'Fredoka', fontSize: 21, fontWeight: FontWeight.w600),
      titleMedium: TextStyle(fontFamily: 'Fredoka', fontSize: 16, fontWeight: FontWeight.w600),
      labelLarge: TextStyle(fontFamily: 'Fredoka', fontSize: 17, fontWeight: FontWeight.w600),
      bodyLarge: TextStyle(fontSize: 15),
      labelMedium: TextStyle(fontSize: 13, fontWeight: FontWeight.w700),
      bodySmall: TextStyle(fontSize: 12.5),
    ),
    inputDecorationTheme: InputDecorationTheme(
      filled: true,
      fillColor: Colors.white,
      contentPadding: const EdgeInsets.symmetric(horizontal: 14, vertical: 16),
      enabledBorder: border(_line, 1.5),
      focusedBorder: border(_primary, 2),
      errorBorder: border(const Color(0xFFB3261E), 2),
      focusedErrorBorder: border(const Color(0xFFB3261E), 2),
    ),
    filledButtonTheme: FilledButtonThemeData(
      style: FilledButton.styleFrom(
        minimumSize: const Size.fromHeight(54),
        shape: const StadiumBorder(),
      ),
    ),
    outlinedButtonTheme: OutlinedButtonThemeData(
      style: OutlinedButton.styleFrom(
        minimumSize: const Size.fromHeight(54),
        shape: const StadiumBorder(),
        side: const BorderSide(color: _primary, width: 1.5),
      ),
    ),
  );
}

Register the fonts with these family names in pubspec.yaml:

  fonts:
    - family: Fredoka
      fonts:
        - asset: assets/fonts/Fredoka-SemiBold.ttf
          weight: 600
    - family: NunitoSans
      fonts:
        - asset: assets/fonts/NunitoSans-Regular.ttf
        - asset: assets/fonts/NunitoSans-Bold.ttf
          weight: 700
